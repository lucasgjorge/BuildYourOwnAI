# BDD - BuildYourOwnAI

Cenários de comportamento em Gherkin (português), organizados por funcionalidade.

## Organização

- `01-autenticacao.feature`
- `02-organizacoes.feature`
- `03-documentos.feature`
- `04-assistentes.feature`
- `05-chat-e-escolha-automatica.feature`
- `06-fontes-e-previa.feature`
- `07-lacunas.feature`
- `08-estudar.feature`
- `09-regras-transversais.feature`

## Observação

Os cenários foram elaborados a partir do README e das especificações/PRD disponíveis no repositório. São especificações BDD para documentação e futura validação; não representam testes automatizados executáveis enquanto não houver configuração de um runner BDD e implementação dos passos (`steps`).

Cenários que dependem de comportamento não detalhado nas especificações devem ser refinados durante a validação com o produto.
